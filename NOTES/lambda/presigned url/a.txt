# LAMBDA 1: PRESIGNED URL GENERATOR

## Problem It Solves
Direct browser uploads via API Gateway/Lambda face hard architectural ceilings:
- 6MB maximum payload size limit.
- 30-second API Gateway HTTP timeout.
- Cost and memory overhead from buffering large CSV payloads in Lambda memory.

## Architectural Solution (Presigned S3 URL)
Instead of streaming file bytes through Lambda, the frontend requests a temporary signed upload ticket:
1. Browser calls `GET /upload-url`.
2. Lambda generates a presigned S3 PUT URL (valid for 300 seconds) with a unique batch UUID.
3. Browser uploads the raw CSV file directly to Amazon S3 via `PUT`.
4. The upload completely bypasses Lambda runtime limits, supporting multi-gigabyte datasets with zero latency bottlenecks.

## Event Flow
```
Browser ──(GET /upload-url)──> API Gateway ──> getPresignedUrl Lambda 
Browser <──(Signed S3 URL + Batch ID)─────────┘
Browser ──(Direct PUT)──> Amazon S3 Bucket
```
