# =============================================================================
# LAMBDA 2: CSV Processor
# =============================================================================
# WHAT THIS DOES:
#   When a CSV file lands in S3, this Lambda is triggered automatically.
#   It downloads the CSV, parses every row, and inserts the users into
#   our PostgreSQL database. Then it calls n8n's webhook to trigger
#   Workflow B (the user-loan matching engine).
#
# HOW IT'S TRIGGERED:
#   S3 "Event Notification" — when any file is created in the uploads/ folder,
#   S3 sends an event to this Lambda. This is configured in serverless.yml.
#   You don't call this Lambda manually; S3 calls it for you.
#
# THE EVENT OBJECT:
#   When S3 triggers a Lambda, it sends a JSON event containing:
#   {
#     "Records": [{
#       "s3": {
#         "bucket": { "name": "clickpe-csv-uploads" },
#         "object": { "key": "uploads/abc-123.csv" }
#       }
#     }]
#   }
#   We extract the bucket name and file key from this to download the file.
#
# FLOW:
#   S3 event → this Lambda → download CSV from S3 → parse rows →
#   INSERT into Postgres → call n8n webhook (trigger Workflow B)
# =============================================================================
