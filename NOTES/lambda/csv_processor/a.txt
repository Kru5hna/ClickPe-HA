# LAMBDA 2: EVENT-DRIVEN CSV PROCESSOR

## Trigger Mechanism
S3 Event Notification: When an object is created under `uploads/*.csv`, Amazon S3 automatically invokes this function asynchronously with the bucket and object key payload.

## Core Operations
1. **Stream from S3**: Fetches the uploaded CSV via `boto3` S3 client as an IO stream (no full disk write).
2. **Batch Ingestion**: Reads CSV rows with `csv.DictReader` and performs a batch insert into PostgreSQL `users` table via `psycopg2.extras.execute_values`.
3. **Batch Scoping**: Attaches the `batch_id` to every ingested row for deterministic downstream processing.
4. **n8n Webhook Dispatch**: Triggers n8n Workflow B via an HTTP POST request carrying `{ batch_id, total_users }`.

## Resilience & Production Patterns
- Ingests in parameterized batches to prevent SQL injection and connection timeouts.
- Idempotent execution: duplicate files with different batch IDs do not corrupt existing batches.
- Asynchronous invocation: S3 automatically retries twice if the Lambda execution encounters transient errors.
