
# DOCKER COMPOSE — Runs n8n + PostgreSQL on your machine

# WHY DOCKER COMPOSE?
#   Instead of installing Postgres and n8n separately, Docker Compose lets you
#   define both services in one file and start them with `docker compose up`.
#   The task specifically requires: "docker-compose.yml for launching your
#   self-hosted n8n instance."
#
# HOW IT WORKS:
#   - Docker creates an isolated network where both containers can talk
#   - Postgres is the database; n8n is the workflow engine
#   - n8n connects to Postgres using the hostname "postgres" (the service name)
#   - Data is persisted in Docker "volumes" so it survives container restarts
